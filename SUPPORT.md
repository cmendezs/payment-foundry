# Support

This is a solo-maintained, volunteer open-source project. Response times are
best-effort.

## Where to go

| I want to... | Go here |
|---|---|
| Ask a "how do I" question | [Issues](https://github.com/cmendezs/payment-foundry/issues/new/choose) |
| Report a bug | [Issues](https://github.com/cmendezs/payment-foundry/issues/new/choose) |
| Request a feature, or PSP support | [Issues](https://github.com/cmendezs/payment-foundry/issues/new/choose) |
| Report a security vulnerability | See [SECURITY.md](SECURITY.md), do not open a public issue |
| Contribute a fix or feature | See [CONTRIBUTING.md](CONTRIBUTING.md) |

Discussions are not enabled on this repository; use Issues for questions as
well as bugs and feature requests.

## Before you open something

A quick search of open and closed issues saves everyone time; there is a
reasonable chance your question or bug has already been answered.
